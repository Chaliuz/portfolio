Resumen

Plataforma de educación en trading que desarrollé desde cero junto a un socio. Yo me encargué del backend y de gran parte del frontend, incluyendo el sistema de cobros.

El problema

La plataforma debía permitir practicar y aprender trading, y cobrar suscripciones de forma segura y automática, con control de accesos según el plan.

La solución

Construí la API con Django REST Framework y el frontend con Next.js. Implementé el ciclo completo de pagos: generación de checkout, validación por webhook y control de vigencia de la suscripción. Empecé con Openpay y migré a dLocal Go. Integré la librería de gráficos de TradingView.

Arquitectura

  • Backend: Django REST Framework con autenticación por token/JWT.
  • Base de datos PostgreSQL, caché con Redis y tareas asíncronas con Celery.
  • Frontend: Next.js consumiendo la API.
  • Despliegue con Docker en AWS.
  • Pagos: Openpay → dLocal Go, con webhooks que validan la transacción y acumulan tiempo de suscripción.

Aprendizajes

  • Diseñar e implementar integraciones con pasarelas de pago y webhooks.
  • Manejar suscripciones, validación de pagos y estados de cuenta.
  • Desplegar un stack completo (Django + Next + Postgres + Redis + Celery) en AWS.
